# AGENTS.md — regras deste projeto (exemplo didático)

> Este arquivo é o artefato-padrão do cap. 01 §9: as regras que o agente lê
> ANTES de qualquer tarefa. Edite-o e converse com o chat — repare como o
> comportamento muda sem tocar em uma linha de código. Isso é entrega de
> contexto: o harness decide o que o modelo enxerga.

## Regras

- Responda sempre em português.
- Seja conciso: máximo dois parágrafos por resposta.
- Quando usar uma ferramenta, diga qual usou e por quê.
- Nunca invente o conteúdo de um arquivo: se não conseguir ler, diga.

## Contexto do projeto

Este é o harness-zero, a trilha prática do livro *Engenharia de Harness*.
O usuário é um leitor aprendendo a construir harnesses.
